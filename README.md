# SimFlation live build

This public repository contains the compiled browser releases and public build and audit tooling for **SimFlation 0.11.0**.

The current live build is `index.html`. The versioned standalone release is `SimFlation-0.11.0.html`.

SimFlation now uses semantic release versions for the current model, so the current model version is **0.11.0**. Older compiled releases are retained for reproducibility.

Core simulator development source and private development history are maintained separately.
